**Descrição do Projeto:**

O projeto consiste em uma aplicação web de autenticação de usuários desenvolvida utilizando PHP e os princípios da Programação Orientada a Objetos (POO). O projeto permite o cadastro de novos usuários, login, exibição de uma área com informações do usuário logado, a opção de lembrar o e-mail e a funcionalidade de logout.

**Instruções para Executar Localmente:**

Para executar esta aplicação localmente, você precisará de um ambiente de desenvolvimento web que suporte PHP.

1.  **Instalar um Servidor Web com PHP:**
    * **XAMPP:** (Recomendado para iniciantes) Disponível para Windows, macOS e Linux. Ele inclui Apache (servidor web), MySQL (banco de dados, embora este projeto não o utilize), e PHP.
      
2.  **Clonar o Repositório (Após Criá-lo no GitHub):**
   Depois de criar este repositório público no GitHub, clone-o para o seu computador utilizando o comando `git clone`

3.  **Copiar os Arquivos para o Diretório Raiz do Servidor Web:**
    Depois de clonar o repositório, copie todos os arquivos (as pastas `classes` e os arquivos `.php` na raiz) para o diretório de documentos do seu servidor web local. A localização desse diretório varia dependendo do servidor que está utilizando:
